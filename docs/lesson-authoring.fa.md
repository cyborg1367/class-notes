# نگارش یادداشت با قالب مشترک

قرارداد اصلی و مالکیت اجزا در [lesson-reference.fa.md](lesson-reference.fa.md) است. برای شروع از [templates/lesson-body.html](templates/lesson-body.html) استفاده کنید.

نویسنده، محتوای آموزشی و ساختار معنایی را آماده می‌کند. React هدر، مشخصات مدرس، نوار سه نکته، ستون‌ها، اجزای بدنه، پیشرفت مطالعه و منابع را می‌سازد. متن خصوصی در Supabase باقی می‌ماند.

هر پاراگراف یک ایدهٔ کامل دارد. جمله‌های مرتبط را با نقطه ادامه دهید؛ بعد از هر جمله پاراگراف یا br جدید نسازید. تیترها و شناسهٔ بخش‌ها واضح و ثابت باشند. تأکید با strong، کد کوتاه با code، کد چندخطی با pre/code و جدول با table/thead/tbody نوشته می‌شود.

در frontend/reader/lesson-presentation.ts برای هر درس دقیقاً سه نکتهٔ آموزشی تعریف کنید. عنوان، مقدمه و تصویر با موضوع درس عوض می‌شوند؛ جای آن‌ها در صفحه ثابت است. تصویر مرجع alt و توضیح داشته باشد. در بدنه، هدر، دکمهٔ شروع، مشخصات مدرس، سایدبار و کارت منابع را تکرار نکنید.

کد Python را با language-python و خروجی برنامه را با language-text مشخص کنید. نیازی به نوشتن قاب و دکمهٔ کپی نیست. برای استایل متن، کد یا جدول، CSS یا style درون‌خطی مخصوص یادداشت ننویسید. رنگ‌آمیزی تألیفی موجود حفظ می‌شود و کد خام Python توسط هایلایتر مشترک رنگ می‌گیرد.

هر سؤال آزمون زمینهٔ کافی داشته باشد؛ نقش متغیرها و نوع شیءهایی مانند GridSearchCV روشن باشد. کلیدها و پاسخ‌ها خصوصی بمانند و با تغییر سؤال، نسخهٔ تازهٔ آزمون ایجاد شود تا سوابق قبلی حفظ شوند.
