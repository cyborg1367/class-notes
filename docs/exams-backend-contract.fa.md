# قرارداد امتحانات مستقل — Midterm 01

در این نسخه، بخش Exams مستقل از Quizهای یادداشت‌هاست و هیچ تغییری در `classroom_quiz` یا `classroom_submit` اعمال نمی‌کند.

## سیاست قطعی

- ۱۵ سؤال چهارگزینه‌ای: ۶ ساده، ۵ متوسط، ۴ دشوار؛ نمرهٔ هر سؤال ۱، نمرهٔ نهایی از ۱۵.
- ۶۰ دقیقه از لحظهٔ شروع هر دانشجو، بر اساس ساعت سرور. مهلت توسط `started_at` و `expires_at` ثبت و در RPCها کنترل می‌شود.
- دقیقاً **یک تلاش** برای هر دانشجوی عضو فعال در دوره، با قید یکتای `(exam_id,user_id)` در پایگاه داده؛ حتی تلاش منقضی‌شده فرصت جدید ایجاد نمی‌کند.
- ذخیرهٔ خودکار پاسخ‌ها طی آزمون؛ پایان زمان سبب نهایی‌شدن پاسخ‌های ذخیره‌شده می‌شود (با تماس مرورگر، یا در اولین درخواست بعدی به سرور).
- بعد از ثبت نهایی، دانشجو نمره، پاسخ انتخابی خودش، پاسخ درست و دلیل علمی و نکتهٔ آموزشی انتخاب اشتباه را می‌بیند؛ قبل از نهایی‌شدن، کلید پاسخ و دلایل ارسال نمی‌شوند.
- دانشجو بعد از امتحان می‌تواند امتیاز ۱ تا ۵ و نظر اختیاری برای مدرس بفرستد. این نظر روی نمره اثری ندارد.
- **توجه:** بازخورد فوری به معنای این است که دانشجویی که زودتر تحویل می‌دهد می‌تواند کلید پاسخ را با دیگران به اشتراک بگذارد. این تصمیم آگاهانه و مطابق سیاست مدرس است.

## RPC عمومی روی Supabase

| تابع | پارامترها | رفتار |
|---|---|---|
| `classroom_exams` | `p_course text` | فهرست امتحانات، وضعیت و یک تلاش مجاز |
| `classroom_exam` | `p_exam text` | خلاصه امتحان، تلاش جاری یا نتیجهٔ نهایی خود شخص |
| `classroom_exam_start` | `p_exam text` | شروع/ادامه تلاش، سؤال‌ها **بدون پاسخ صحیح** |
| `classroom_exam_save` | `p_id uuid,p_answers jsonb` | ذخیرهٔ پاسخ‌های تلاش معتبر تا زمان انقضا |
| `classroom_exam_submit` | `p_id uuid,p_answers jsonb` | ثبت نهایی و پاسخ‌نامه تشریحی برای همان دانشجو |
| `classroom_exam_attempt` | `p_id uuid` | مشاهده دوباره کارنامه قبلی خود شخص |
| `classroom_exam_feedback` | `p_id uuid,p_rating integer,p_comment text` | ثبت بازخورد درباره امتحان، پس از نهایی شدن |

## نگهداری اطلاعات حساس

- پاسخ صحیح با نام فیلد `correct_option` فقط در Supabase خصوصی است و پس از ثبت نهایی در کارنامهٔ صاحب تلاش قرار می‌گیرد.
- **فایل SQL خصوصی، JSON بانک سؤال، کلیدهای صحیح و توضیح پاسخ‌ها هرگز داخل GitHub/فرانت‌اند/پوشهٔ `web` یا `dist` قرار نگیرند.**
- جدول‌های داخلی در `classroom_exam_private` ساخته می‌شوند و دسترسی مستقیم `anon`/`authenticated` به آن‌ها وجود ندارد؛ توابع `public` با `SECURITY DEFINER` و `auth.uid()` دسترسی را کنترل می‌کنند.
- سیستم برای بررسی عضویت فعال از **RPC موجود `public.classroom_state()`** استفاده می‌کند و ساختار جدول عضویت را حدس نمی‌زند. قبل از اجرای SQL خصوصی مطمئن شوید تابع بدون پارامتر موجود است و در خروجی، `memberships` شامل `course_id` و `status` می‌شود.
- SQL اولیه امتحان را با `published=false` ایجاد می‌کند. بعد از بررسی دستی می‌توان آن را فعال کرد.

فایل SQL و کلیدها در ZIP عمومی پروژه قرار ندارند. راهنمای دقیق اجرا: `docs/EXAMS-INSTALL.fa.md`.
