# ارتقای Exams به نسخه V4

این راهنما مخصوص نصب دستی روی پروژهٔ موجود Class Notes است. هیچ نیازی به اتصال GitHub یا Supabase به ChatGPT نیست.

## ۱. قبل از شروع

- از وضعیت فعلی کد و دیتابیس نسخهٔ پشتیبان داشته باشید.
- فایل `01-exam-access-and-teacher-results.sql` را **فقط** در Supabase SQL Editor اجرا کنید؛ در GitHub یا فایل‌های `web/` قرار ندهید.
- این ارتقا بر اساس نسخهٔ قبلی `exams-setup-private.sql` طراحی شده است و تلاش‌های قبلی دانشجویان را پاک نمی‌کند.

## ۲. نصب Supabase

۱. پروژهٔ صحیح را از Supabase Dashboard باز کنید.
۲. SQL Editor → New query.
۳. محتوای فایل SQL خصوصی V4 را Paste کنید و Run بزنید.
۴. این اجرا امتحان را `published=true` نگه می‌دارد؛ دانشجویان فقط با کد صحیح می‌توانند **تلاش جدید** شروع کنند.
۵. مدرسِ دارای نقش `teacher` در عضویت فعال کلاس می‌تواند بدون کد، نامحدود تلاش آزمایشی ایجاد کند. هر تلاش آزمایشی پس از Submit یا پایان زمان، بسته می‌شود؛ تلاش بعدی سپس مجاز است.

### بررسی پس از اجرا

```sql
SELECT id, published, access_code_hash IS NOT NULL AS code_is_configured
FROM classroom_exam_private.exams
WHERE id = 'machine-learning-midterm';
```

نتیجهٔ مورد انتظار: `published=true` و `code_is_configured=true`.

```sql
SELECT proname, pg_get_function_identity_arguments(oid) AS arguments
FROM pg_proc
WHERE pronamespace = 'public'::regnamespace
  AND proname IN ('classroom_exam_start','classroom_instructor_exam_results','classroom_instructor_exam_result');
```

برای تابع شروع باید فقط امضای **دو پارامتر** `p_exam text, p_code text` وجود داشته باشد؛ نسخهٔ تک‌پارامتری حذف شده است تا ورود بدون کد ممکن نباشد.

```sql
SELECT indexname, indexdef FROM pg_indexes
WHERE schemaname='classroom_exam_private' AND tablename='attempts'
  AND indexname IN ('exam_student_one_attempt_uq','exam_teacher_one_active_preview_uq');
```

### توجه به سوابق گذشته

تلاش‌های موجود دانشجویان حفظ می‌شوند و همچنان فرصت دوم ندارند. تلاش‌های جدید مدرس با `is_preview=true` ثبت می‌شوند و در گزارش دانشجویان شمرده نمی‌شوند. اگر مدرس پیش از این ارتقا با حساب خودش امتحان داده باشد، تلاش قدیمی با پرچم `false` باقی می‌ماند؛ برای خارج کردن همان سابقه از گزارش، ابتدا شناسهٔ حساب را در Supabase بررسی کنید و سپس فقط همان تلاش را با احتیاط به حالت آزمایشی تغییر دهید. سوابق دانشجویان را تغییر ندهید.

## ۳. نصب فایل‌های سایت

فایل ZIP عمومی V4 را در **روت فعلی** پروژه (`class-notes/` کنار `package.json`) استخراج و Merge/Overwrite کنید. فایل‌های دیگر را پاک نکنید.

داخل روت پروژه در PowerShell:

```powershell
npm.cmd ci
npm.cmd run check
```

در صورت موفقیت Build:

```powershell
npx.cmd wrangler dev --local --port 8787
```

سپس `/exams/machine-learning-midterm/` و `/instructor/` را در محیط محلی باز کنید. نسخهٔ محلی ممکن است به Supabase واقعی متصل شود؛ برای آزمون دانشجویی از حساب آزمایشی استفاده کنید. هر دانشجو فقط یک بار می‌تواند تلاش جدید شروع کند.

## ۴. تست دستی نهایی

- با حساب دانشجوی تازهٔ فعال: کد اشتباه را وارد کنید. شروع باید رد شود **بدون ثبت تلاش جدید**.
- کد درست را وارد کنید. آزمون باید شروع شود؛ Refresh باید همان تلاش را ادامه دهد.
- پس از Submit، نمره، پاسخ صحیح و دلیل هر سؤال باید دیده شود؛ تلاش دوم برای دانشجو رد شود.
- با حساب مدرس (نقش فعال `teacher`): بدون کد شروع کنید، Submit کنید و روی «شروع تلاش آزمایشی جدید» بزنید. این کار باید بارها امکان‌پذیر باشد.
- در پنل مدرس، «میان‌ترم و امتحانات» را باز کنید؛ نتایج دانشجویان، بازخوردها و جزئیات سؤال‌ها باید دیده شوند؛ تلاش‌های **جدید** مدرس نباید در گزارش باشند.
- فرمول سؤال‌های ۱، ۳ و ۱۰ و توضیحاتشان باید با KaTeX نمایش داده شوند، نه با بک‌اسلش خام.
- Confusion Matrix سؤال ۴ باید جدول واقعی با محورهای کلاس واقعی/پیش‌بینی‌شده باشد.
- در دسکتاپ و موبایل بررسی کنید گزینه‌ها از **راست** شروع شوند و نمودار Validation Curve هیچ هم‌پوشانی نداشته باشد.

## ۵. معماری امنیتی

- کد ورود و کلیدهای صحیح فقط در Supabase نگهداری می‌شوند؛ در ZIP عمومی وجود ندارند.
- دانشجو نمی‌تواند با جعل گزینهٔ «مدرس» از محدودیت عبور کند؛ نقش مدرس توسط سرور و عضویت فعال کلاس تعیین می‌شود.
- گزارش‌های پنل مدرس از طریق RPCهایی دریافت می‌شوند که مجوز مدرس را **در سرور** تأیید می‌کنند.
- تا قبل از Submit، کلید پاسخ در API آزمون دانشجو ارسال نمی‌شود.
- هرگونه خطای SQL را قبل از Push برطرف کنید؛ این نسخه از طریق خود ChatGPT روی دیتابیس شما اجرا نشده است.
