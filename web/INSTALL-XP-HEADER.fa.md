# نصب کارت حلقه‌ای XP — نسخهٔ 3.0.4

این بسته برای نسخهٔ فعلی لابراتور E2B است. کارت بالای صفحه را با حلقه‌ای هماهنگ با پنجرهٔ جشن دریافت XP جایگزین می‌کند. برای نمونه، 160 داخل حلقه، of 300 XP زیر آن و متن‌های 4 of 6 missions completed و 53% complete کنار حلقه دیده می‌شوند. همهٔ عددها و متن‌های این کارت انگلیسی‌اند. حلقه از XP تأییدشدهٔ سرور پر می‌شود و در پایان 300 XP رنگ طلایی می‌گیرد.

## ۱. فایل‌ها را جایگزین کن

ZIP را خارج از مخزن استخراج کن. در همان مخزنی که قبلاً با آن سایت را منتشر کردی، این سه فایل را کپی و جایگزین کن:

```text
web/assets/coding-lab.js
web/assets/coding-lab.css
web/lab/machine-learning/vector-distance/index.html
```

**این یک بستهٔ جزئی است. فایل‌ها را در پوشه‌های موجود ادغام کن؛ کل پوشهٔ web را حذف یا با پوشهٔ ناقص این بسته جایگزین نکن.** فایل راهنما را لازم نیست وارد مخزن کنی.

این فایل‌ها قابلیت جشن دریافت XP نسخهٔ 3.0.3 را هم در خود دارند. برای این تغییر نیازی به اجرای SQL، تغییر Supabase، تنظیم کلیدها یا انتشار دوبارهٔ تابع E2B نیست.

## ۲. بررسی و پوش

ترمینال را در ریشهٔ مخزن خودت باز کن؛ همان جایی که build.py و check.py هستند:

```bash
python3 build.py
python3 check.py
git diff --check
git status --short
```

اگر ویندوز داری و python3 شناخته نمی‌شود، از python استفاده کن. پس از موفق بودن بررسی‌ها، سه فایل را ثبت و به شاخهٔ انتشار فعلی پوش کن؛ دستور زیر برای شاخهٔ main است:

```bash
git add web/assets/coding-lab.js web/assets/coding-lab.css web/lab/machine-learning/vector-distance/index.html
git commit -m "Replace lab progress bar with English XP ring"
git push origin main
```

## ۳. نتیجه را ببین

پس از سبز شدن اجرای انتشار در GitHub Actions، صفحهٔ لابراتور را با Ctrl+Shift+R تازه‌سازی کن (در مک Cmd+Shift+R). نسخهٔ کش فایل‌های لابراتور به 3.0.4 تغییر کرده است.

کارت باید همان XP ذخیره‌شدهٔ قبلی را فوراً نمایش دهد؛ برای دیدن آن لازم نیست تسک تازه‌ای حل کنی. مثلاً با 160 XP و چهار تسک کامل‌شده، باید 160، of 300 XP، 4 of 6 missions completed و 53% complete دیده شود. پنجرهٔ جشن همچنان فقط پس از دریافت XP تازه باز می‌شود. تسکِ تکراری XP اضافه نمی‌دهد.

۲۸ آزمون منطق رابط و مدل پاس شده‌اند؛ بازیابی XP قبلی، دریافت امتیاز تازه، پایان مأموریت و جلوگیری از XP محلی بررسی شده است. ساخت سایت و بررسی مسیرها و فایل‌ها هم موفق بوده‌اند. بررسی دیداری در مرورگر این محیط ممکن نبود؛ ظاهر دسکتاپ و موبایل را پس از انتشار نگاه کن.
