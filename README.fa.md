دفتر کلاس — نسخهٔ ۲

این پوشه فقط برنامهٔ عمومی سایت است. فایل‌های این پوشه را در ریشهٔ مخزن قرار بده و Workflow قبلی داخل .github را نگه دار.

ساخت: python3 build.py
بررسی: python3 check.py

برای راه‌اندازی عضویت کلاس، محتوای خصوصی و ارزیابی آزمون‌ها، راهنمای START-HERE در بستهٔ جداگانهٔ INSTRUCTOR-ONLY را دنبال کن. بستهٔ خصوصی نباید در این مخزن آپلود شود.

برای پیش‌نمایش ظاهر صفحهٔ اصلی روی کامپیوتر، web/index.html را باز کن. ورود و دریافت محتوا به انتشار روی HTTPS و تنظیم Supabase نیاز دارند.
