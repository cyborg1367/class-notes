# دفتر کلاس — نسخهٔ ۳.۶.۰

سایت عمومی روی GitHub Pages است. ورود، جزوه‌ها، آزمون‌ها و پیشرفت دانشجو با Supabase کنترل می‌شوند.

دو لابراتور «کارآگاه گلخانه» و «کارآگاه پیامک» هرکدام شش مأموریت و ۳۰۰ XP مستقل دارند. معرفی آغازین، داستان و داده‌های تمرین را توضیح می‌دهد. بازخورد بررسی در پاپ‌آپ کاغذی با راهنمای اختیاری نمایش داده می‌شود؛ خطاهای اجرای محلی در کنسول می‌مانند.

اجرای آزمایشی در مرورگر است. بررسی مستقل از طریق Supabase و محیط E2B انجام می‌شود و تنها سرور XP ثبت می‌کند. داشبورد، پیشرفت هر دو لابراتور و مجموع ۶۰۰ XP را نشان می‌دهد.

برای ارتقا از نسخهٔ ۳.۵ به ۳.۶، فایل‌های عمومی و Edge Function از بستهٔ ارتقا به‌روزرسانی می‌شوند؛ SQL جدید لازم نیست. شناسهٔ مأموریت دوم برای حفظ XP و کدهای قبلی ثابت مانده است. فایل‌های مدرس و کلیدها را در مخزن عمومی قرار نده.

```bash
python3 build.py
python3 check.py
```

`web/assets/auth-config.json` فقط تنظیم عمومی ورود را نگه می‌دارد و `web/assets/lab-service.json` فقط آدرس عمومی بررسی را دارد. این دو فایل هنگام ارتقا با تنظیمات پروژهٔ خودت حفظ می‌شوند.
