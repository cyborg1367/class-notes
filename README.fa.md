# دفتر کلاس

وب‌سایت فارسی و راست‌به‌چپ برای انتشار جزوه‌های کلاس. طراحی از نمونهٔ ارسالی اقتباس شده است. متن و کدهای جزوهٔ «از یک جدول تا نزدیک‌ترین نمونه» در نسخهٔ وب حفظ شده‌اند؛ پاسخ تمرین اصلی نمایش داده نمی‌شود.

## فایل‌ها

- `site.json`: نام مدرس در `instructor`، اطلاعات کلاس‌ها، ترتیب درس‌ها و فهرست بخش‌های هر درس.
- `content/`: متن HTML درس‌ها؛ محتوای آموزشی از قالب و استایل جداست.
- `assets/`: فونت وزیرمتن، شکل‌ها، PDF، کدهای تعاملی و کتابخانهٔ محلی KaTeX.
- `build.py`: تولید سایت استاتیک با کتابخانهٔ استاندارد پایتون؛ بدون نصب وابستگی.
- `dist/`: سایت آمادهٔ انتشار.
- `.github/workflows/pages.yml`: ساخت و انتشار خودکار روی GitHub Pages.
- `content/_lesson-template.html`: نمونهٔ شروع برای درس بعدی؛ خودش منتشر نمی‌شود.

## انتشار روی GitHub Pages

۱. یک مخزن GitHub بسازید و **فایل‌های همین بسته را در ریشهٔ آن** قرار دهید. پوشهٔ `.github` هم باید منتقل شود. شاخهٔ پیش‌فرض این تنظیمات `main` است.

۲. در تنظیمات مخزن، مسیر **Settings → Pages → Build and deployment → Source** را باز کنید و **GitHub Actions** را انتخاب کنید.

۳. با هر push به `main`، فایل workflow سایت را می‌سازد و منتشر می‌کند. وضعیت را در زبانهٔ **Actions** می‌بینید. اگر تغییر قبلی پیش از تنظیم Pages انجام شده بود، workflow را دستی با **Run workflow** اجرا کنید.

۴. نشانی عمومی پس از اجرای موفق در Settings → Pages نمایش داده می‌شود. می‌توانید لینک مستقیم هر جزوه را به دانشجویان بدهید؛ برای نمونه:

`https://USERNAME.github.io/REPOSITORY/machine-learning/vector-distance/`

نام کاربری و مخزن را با اطلاعات واقعی خودتان جایگزین کنید. سایت از مسیرهای نسبی استفاده می‌کند و هم در ریشهٔ دامنه و هم زیر نام مخزن کار می‌کند.

**روش بدون build:** محتویات پوشهٔ `dist/` را در ریشهٔ یک مخزن دیگر قرار دهید، سپس Source را روی **Deploy from a branch** و شاخهٔ `main` و پوشهٔ `/(root)` تنظیم کنید.

مستندات رسمی: [انتخاب منبع انتشار](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site) و [workflow سفارشی Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

## اضافه کردن درس بعدی

۱. از `content/_lesson-template.html` کپی بگیرید؛ مثلاً در `content/machine-learning/next-lesson.html`.

۲. متن را در آن بنویسید. هر بخش باید یک `id` یکتا داشته باشد. بخش‌های خواندنی را داخل `lesson-section` نگه دارید. بلوک‌های کد و کلاس‌های CSS موجود قابل استفاده‌اند.

۳. به آرایهٔ `lessons` در کلاس موردنظر در `site.json` یک ورودی اضافه کنید:

```json
{
  "slug": "next-lesson",
  "title": "عنوان درس جدید",
  "subtitle": "توضیح کوتاه",
  "description": "خلاصه‌ای برای فهرست درس‌ها",
  "number": "02",
  "source": "content/machine-learning/next-lesson.html",
  "hero_intro": "<p class=\"\">متن آغاز درس</p>",
  "sections": [{"id": "introduction", "label": "شروع درس"}],
  "tags": ["NumPy"]
}
```

عنوان بخش‌ها در `sections` باید با idهای فایل محتوا هماهنگ باشد. `slug` را به انگلیسی و با حروف کوچک و خط تیره بنویسید. برای افزودن یک کلاس دیگر، یک ورودی تازه در آرایهٔ `courses` بسازید و دست‌کم یک درس به آن بدهید.

۴. اگر PDF دارید، آن را در `assets/` بگذارید و کلید اختیاری `pdf` را با نام فایل به درس اضافه کنید.

۵. برای فرمول جدید، LaTeX را در `data-tex` بنویسید. KaTeX از فایل‌های محلی بارگذاری می‌شود:

```html
<div class="formula-card lesson-formula"
     data-tex="d=\sqrt{x^2+y^2}"></div>
```

۶. فایل‌ها را commit و push کنید؛ فهرست و مسیر درس جدید خودکار تولید می‌شود.

## ساخت محلی

```sh
python3 build.py
python3 check.py
```

برای تست توابع محاسباتی و جست‌وجو، در صورت داشتن Node.js:

```sh
node --test tests/*.test.cjs
```

## رفتارهای تعاملی

کپی کد، فهرست فعال هنگام پیمایش، جست‌وجوی کلاس، نمایش بردار یک سطر یا ستون و تغییر مثال مستقلِ فاصله فعال‌اند. محاسبهٔ تعاملی فقط روی بردارهای مثال حل‌شده انجام می‌شود؛ رتبه‌بندی دادهٔ تمرین پیاده‌سازی نشده است. پاسخ‌های نوشته‌شده در کاربرگ فقط در مرورگر همان دانشجو ذخیره می‌شوند و به سروری ارسال نمی‌شوند.

نماهای سه‌بعدی با ماوس، لمس، دکمه‌های جهت و صفحه‌کلید قابل چرخش‌اند. برای استفاده با صفحه‌کلید، نمودار را با Tab انتخاب کنید؛ کلیدهای جهت زاویه را تغییر می‌دهند و Home نمای اولیه را بازمی‌گرداند. چرخش فقط دوربین را تغییر می‌دهد؛ مختصات و فاصله‌ها ثابت‌اند. نقاطِ نمای آغازین مستقل از دادهٔ تمرین‌اند. در نبود JavaScript یا هنگام چاپ، تصویر ثابت نمایش داده می‌شود. هیچ کتابخانه یا CDN تازه‌ای برای این نما لازم نیست.

نشان سایت یک SVG با ترکیب کتاب باز و حرف M است؛ `assets/logo.svg` برای هویت سایت و `assets/favicon.svg` برای آیکون زبانه استفاده می‌شود.

فونت‌ها، شکل‌ها، KaTeX و PDF همراه بسته‌اند و سایت برای این منابع به CDN وابسته نیست. مجوزهای فونت و KaTeX در پوشهٔ assets قرار دارند. برای محتوای آموزشی و طراحی، مجوز عمومی تازه‌ای تعیین نشده است؛ تصمیم دربارهٔ مجوز انتشار با صاحب محتواست.
