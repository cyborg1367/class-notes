# دفتر کلاس — نسخهٔ ۳.۰.۱

سایت عمومی روی GitHub Pages است. ورود، جزوه‌ها، آزمون‌ها و پیشرفت دانشجو با Supabase کنترل می‌شوند.

لابراتور جزوهٔ اول، مأموریت گلخانه با دادهٔ تازه، شش تسک و ۳۰۰ XP دارد. اجرای آزمایشی در مرورگر است؛ بررسی نهایی از طریق Supabase و Sandbox جداگانهٔ E2B انجام می‌شود. XP فقط پس از تأیید مستقل ثبت می‌شود و در داشبورد دانشجو و گزارش مدرس نمایش داده می‌شود.

راهنمای ارتقا: `UPDATE-3.0.fa.md`. راه‌اندازی E2B، Edge Function و SQLهای 007 و 008 در بستهٔ مخصوص مدرس توضیح داده شده است. فقط بستهٔ عمومی را در این مخزن قرار بده؛ منبع مخصوص مدرس و کلیدهای مدیریتی نباید عمومی شوند.

```bash
python3 build.py
python3 check.py
```

`web/assets/auth-config.json` فقط تنظیم عمومی ورود را نگه می‌دارد. `web/assets/lab-service.json` فقط آدرس عمومی بررسی را دارد. اجرای SQL یا push به‌تنهایی اتصال E2B را فعال نمی‌کند.
